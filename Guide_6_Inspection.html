Set up an inspection (NYC)

The sheet is drawn with made-up sample data, because the real workbook holds live orders.

  1. Find the Inspection Tracker

    Go to SharePoint and sign in with your Metro1 Microsoft account. Search for Inspection Tracker. If it doesn't show, ask Saul for access.

  2. Open it in the Excel app

    Click the three dots beside the file. Then click Open, then Open in app. Clicking the file's name usually opens the browser, and this file must not be opened there.

  3. Add a row for each style

    Do this when the PO is placed. Each row is one style on one PO. Use the tab with the columns drawn in the next step, not the Instructions tab.

  4. Fill in columns A to G

    These are the NYC columns:

    • PO#: the PO number. For a bulk PO, also write "bulk" here, as in 900003 bulk. A bulk PO has Order Type Bulk on the PO Status Tracker. See Production & PO Tracking.
    • Factory: the factory's name.
    • Customer PO#: one per line if there are several.
    • Ticketed: Yes or No. Tickets are retail price tickets or labels.
    • Description and Style: the item.
    • M1S Specific Instructions: one instruction per line.

    Scroll the table sideways to see every column.

  5. Leave columns H to M empty

    HK fills those in.

Record the inspection (HK)

  1. Open the workbook

    Open it in the Excel app. The first two steps of Set up an inspection show how.

  2. Find the row

    Find the PO# and Style. A finished row looks like the first three below. The last row is still waiting for its result, and has no ETD because its PO isn't booked yet.

    Scroll the table sideways to see every column. PO# and Style are NYC columns. They're drawn here so you can see which row is which.

  3. Enter the inspection date

    Fill in Scheduled Inspection Date.

  4. Enter the result

    In Inspection Result, enter PASS or FAIL. If it's FAIL, also follow Handle a failed inspection.

  5. Add your notes for NYC

    In Notes for NYC HQ, add the CBM, vessel, port and any combined inspections.

  6. Enter the Report #

    This is the inspection report's number. Use IR and the next available number, as in IR0412.

  7. Enter the Charge#

    Use the inspector's code, then the inspection date as MMDDYYYY. Code S on November 18, 2026 is S11182026. The codes are under Inspector codes.

    The same inspector on the same date gives the same Charge#, so one can cover several reports.

  8. Enter the ETD once the PO is booked

    Fill in ETD once the PO is booked. If it isn't booked yet, leave it blank and come back to it. ETD is the Estimated Time of Departure.

Handle a failed inspection

  1. Keep the failed row

    It stays on the sheet with FAIL, its Report # and its Charge#.

  2. Re-enter the failed styles on new rows

    In PO#, write "Reinspection PO" and the PO number, as in Reinspection PO 900002.

  3. Enter the new result

    On the new row, Inspection Result is REINSPECTION-PASS or REINSPECTION-FAIL.

  4. Start the new Report # with R-

    Use R- and the next IR number, as in R-IR0414. The new row also gets its own Charge#.

    Scroll the table sideways to see all 13 columns.

Next in the Production flow

Production's turn. Production fills in Inspection Report on the PO Status Tracker. See Production & PO Tracking. Goods can be booked once carton marks, batch numbers, tickets, PI and inspection are confirmed. Booking is in Plan and book a container.

Rules to remember

  • Open the file in the Excel app, not the browser. Set up an inspection shows how.
  • NYC fills columns A to G. HK fills columns H to M.
  • For a bulk PO, write "bulk" in the PO# field.
  • Re-enter a failed inspection as "Reinspection PO xxxxxx" and mark it REINSPECTION-PASS or REINSPECTION-FAIL.
  • Each inspection gets a Report # and a Charge#. The inspection team is billed off this sheet, so check them.
